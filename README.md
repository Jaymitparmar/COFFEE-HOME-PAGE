# ☕ COFFEE HOME PAGE

A responsive and attractive **Coffee Home Page** created using **HTML5 and CSS3**.

## 📌 About The Project

This project is a coffee-themed website that includes:

* Navigation Bar
* Coffee Banner Section
* Top Categories
* Top Milk Shakes
* Latest Blogs
* Footer Section
* Social Media Icons
* Responsive Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Remix Icon
* Responsive CSS
